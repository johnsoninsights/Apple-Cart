# Apple Cart — E‑Commerce UI for Apple Products

A clean, modern e‑commerce UI for browsing Apple products and adding them to a shopping cart.  
Built with **HTML**, **SCSS**, **JavaScript**, and **Vite**, this project focuses on responsive design, smooth interactions, and a polished Apple‑style layout.

---

## 🚀 Features

- **Product Listing UI**
  - Displays Apple products with images, pricing, and details
  - Clean, minimal Apple‑inspired design

- **Shopping Cart Functionality**
  - Add items to cart
  - Update quantities
  - Remove items
  - Dynamic cart total

- **Fully Responsive Layout**
  - Mobile‑first design
  - Smooth scaling across phones, tablets, and desktops

- **Modern Frontend Workflow**
  - Built with **Vite** for fast development and bundling
  - SCSS for modular, maintainable styling
  - Vanilla JavaScript for cart logic and UI updates

---

## 🛠️ Tech Stack

- **HTML5**
- **SCSS**
- **JavaScript (ES6+)**
- **Vite**
